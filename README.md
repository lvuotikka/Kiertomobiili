Kierto -hyvinvointisovellus (Mobiiliohjelmointi -kurssin lopputyö)
Tekijä: Laura Vuotikka

Kierto on React Native -mobiilisovellus, jonka tarkoituksena on auttaa käyttäjää seuraamaan kuukautiskiertoaan ja siihen liittyvää hyvinvointia. Sovellus tarjoaa tietoa kuukautiskierron eri vaiheista sekä ruoka- ja reseptiehdotuksia eri vaiheisiin.
Ominaisuudet: 
- Kuukautiskierron kalenteri, joka näyttää kierron eri vaiheet väreillä
- Mahdollisuus määrittää kuukautisten alkamispäivä ja kierron pituus
- Kierron vaiheiden ja niiden ominaisuuksien esittely
- Reseptien hakeminen TheMealDB REST API-rajapinnasta
- Reseptien tarkempien tietojen, ainesosien ja valmistusohjeiden näyttäminen
- Päivittäisten hyvinvointimerkintöjen tallentaminen, kuten unen määrä, mieliala, oireet ja muistiinpanot
- Aiemmin tallennettujen hyvinvointimerkintöjen tarkastelu päivämäärän mukaan
- Hyvinvointiin ja kuukautiskiertoon liittyvät ilmoitusmuistutukset
- Käyttäjän asetusten tallentaminen paikallisesti

Käytetyt teknologiat ja kirjastot:
- React Native
- Expo
- TypeScript
- React Native Papers
- React Native Calendars
- Firebase Realtime Database
- AsyncStorage
- TheMealDB REST API
- Expo Notifications

Sovelluksen käynnistäminen:
- Kloonaa GitHub -repositorio
- Asenna riippuvuudet komennolla: npm install
- Käynnistä Expo komenolla: npx expo start
- Avaa sovellus Expo go -sovelluksella mobiililaitteessa
